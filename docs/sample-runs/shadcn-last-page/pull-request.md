# fix(pagination): go to the real last page

## Summary
The 'Go to last page' button set page index to getPageCount() - 2, which is the second-to-last page because pageIndex is zero-based. It should be getPageCount() - 1.

**Actual:** Instead navigated to Page 9 of 10 with page number 9 highlighted, showing TASK-4905, TASK-3437 and other Page 9 tasks instead of the last page
