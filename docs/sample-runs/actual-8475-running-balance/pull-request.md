# fix(accounts): recalculate running balances after transaction edits

## Summary
The optimistic field-edit fast path in updateQuery skipped calculateBalances and assumed a later DB-driven onData would refresh them, but no such refresh occurs for local edits, so the balances map stayed stale. Adjusting the balances locally by the amount delta fixes the edited and newer rows.
